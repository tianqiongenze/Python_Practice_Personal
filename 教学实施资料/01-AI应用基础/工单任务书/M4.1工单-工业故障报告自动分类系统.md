# 工单 M4.1《工业故障报告自动分类系统》（第11周·2课时·难度⭐⭐⭐）

## 一、工作任务
运维部每月数百条故障说明依赖人工派单。构建"分词→去停用词→TF-IDF→分类器"的自动分类系统，实现5类故障文本自动归类（传动/冷却/电气/液压/仪表气动）。

- 数据：`data/fault_reports.csv`（225条，5类均衡）
- 代码框架：`学生代码框架/m41_starter.py`

## 二、资讯导学单（课前）
1. 微课《从文字到向量：菜谱配料表》（4分钟）；
2. 预习自测：TF-IDF中IDF的作用是让____词权重更高；
3. 每人收集2条真实风格故障描述（可仿写），课前提交充实班级语料库。

## 三、任务要求
1. jieba分词 + 停用词过滤（starter附停用词表）；
2. TF-IDF向量化（max_features=2000）；
3. 训练朴素贝叶斯与逻辑回归两个分类器并对比；
4. 对3条**新文本**（自己收集的）做预测验证；
5. 输出每类Top10关键词，解释关键词贡献（哪些词决定"电气系统"类）。

## 四、验收标准
| 等级 | 标准 |
|------|------|
| 及格(D) | 准确率≥0.75；能预测新文本 |
| 良好(C) | 准确率≥0.80；两分类器对比完整 |
| 优秀(B) | 准确率≥0.85；关键词贡献解释清晰 |
| 优(A) | 达B且：混淆矩阵分析（哪两类易混、为何）；自建词典或ngram调优 |

## 五、提交物
代码 + 指标对比表 + Top10关键词表 + 新文本预测记录。

## 六、常见错误
- 未去停用词 → "出现/检查"等高频词淹没专业词；
- 把测试集文本也fit进TF-IDF → 数据泄漏，vectorizer只在训练集fit；
- 类别名当特征泄漏 → 删除label列后再向量化。
