# 工单 M3.1《产品表面缺陷尺寸测量系统》（第9周·2课时·难度⭐⭐⭐）

## 一、工作任务
精密结构件产线需对表面划痕/凹坑进行尺寸测量以判定是否超差。用OpenCV构建"读图→预处理→阈值分割→轮廓检测→尺寸计算→标注输出"的自动测量链路。

- 数据：`data/surface_parts/`（40件，像素当量**0.1mm/px**已标定；`ground_truth.json`为教师核对用，勿下发学生）
- 代码框架：`学生代码框架/m31_starter.py`

## 二、资讯导学单（课前）
1. 微课《阈值分割与轮廓》（4分钟）；
2. 预习自测：像素面积350px²换算物理面积=____mm²（当量0.1mm/px）；
3. 思考：照明不均时全局阈值会怎样？该用什么补救？

## 三、任务要求
1. 完成灰度化→高斯滤波→阈值分割→形态学去噪；
2. `findContours`提取缺陷轮廓，计算：划痕长度（最小外接矩形长边）/凹坑面积（contourArea）；
3. 按像素当量换算物理尺寸（保留2位小数）；
4. 在原图上画框标注缺陷并写尺寸文字，输出标注图。

## 四、验收标准
| 等级 | 标准 |
|------|------|
| 及格(D) | 正确检出并标注缺陷；测量误差<10% |
| 良好(C) | 误差<8%；两种阈值策略对比记录完整 |
| 优秀(B) | 误差<5%；结果图美观清晰（框+文字+图例） |
| 优(A) | 达B且：多缺陷件全部检出；误检率=0并分析成因 |

## 五、提交物
代码 + 标注结果图≥3张 + 测量值与自测真值对比表（教师用ground_truth批改）。

## 六、常见错误
- 面积换算忘记平方：物理面积=像素面积×(0.1)²，不是×0.1；
- 轮廓层级未用 `RETR_EXTERNAL` → 内部轮廓重复计数；
- 阈值二值化方向反了（缺陷暗、背景亮 → 用THRESH_BINARY_INV）。
