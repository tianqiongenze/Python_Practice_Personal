## 决策三件套用法（每工单必做）

1. **备选方案对比**：工单内给出2-3个候选方案；
2. **决策矩阵**：小组按维度打分（0-5），结论写入工单并公示；
3. **决策追责**：第二轮实施后复盘——"如果当初选另一个方案？"
   实施失误必须回溯决策环节（写入反思改进）。

## 环境要点

- Python 3.12+ + venv + Git（第2周起所有工单在模板仓库上开发）；
- 数据库用 **SQLite**（零安装，文件即库），PostgreSQL为选做；
- W5 可视化默认 **Streamlit**（`pip install streamlit plotly`，比Dash轻量）；离线wheel随包；
- W6 复用 `../02-Python编程基础/虚拟产线/` 两个模拟器（或用本包 plc_simulator.py）。
