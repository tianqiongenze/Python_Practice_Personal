# 工单 P2.1《Pandas数据处理管道》（第3周·4课时·难度⭐⭐⭐）

## 任务情境
数据中台收到一个月产线原始数据（1000+行）：缺失/异常/类型不一/重复/时间戳混乱。构建七步管道，质量评分≥85分（starter内置评分脚本）。

## 课前导学单
1. 微课《DataFrame三板斧+三类脏数据》（6分钟）；
2. 预习自测：dropna与fillna的适用场景？
3. `python p21_pipeline.py --peek` 预览数据，数一数问题类型。
