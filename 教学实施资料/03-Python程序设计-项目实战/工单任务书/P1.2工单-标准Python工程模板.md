# 工单 P1.2《标准Python工程模板交付》（第2周·4课时·难度⭐⭐⭐）

## 任务情境
团队即将多人协作，技术委员会要求统一工程底座：后续7个工单全部在本模板上开发——**模板即资产**。

## 课前导学单
1. 微课《venv/Git/项目结构三件套》（6分钟）；
2. 预习自测：requirements.txt的作用？
3. 克隆starter模板仓库并跑通 `pytest tests/`。

## 任务要求
1. **目录结构**：src/ tests/ docs/ data/ config/ + README + .gitignore；
2. **虚拟环境**：venv创建；requirements.txt含本学期全部依赖；
3. **Git规范**：init/add/commit/branch（dev分支开发）；commit message用 `feat:/fix:/docs:` 前缀；
4. **工具链**：pylint或flake8检查 + black格式化配置（.pycharm/settings.json）；
5. **单元测试**：pytest示例1个（针对P1.1第1题写3个断言）；
6. 配置管理：config/settings.yaml（数据库路径等，用PyYAML读取选做）。

## 验收标准
| 等级 | 标准 |
|------|------|
| 及格(D) | venv可用+仓库初始化+结构完整+README |
| 良好(C) | 检查工具配置生效；pytest通过 |
| 优秀(B) | 依赖可还原（requirements完整）；dev分支规范合并 |
| 超优(A) | 优秀+GitHub Actions CI或pre-commit钩子 |

## 提交物
远端仓库URL + 目录树截图 + pylint评分截图（≥8.5/10）

## 避坑
- venv目录提交进仓库（必须.gitignore）；
- 全局Python与venv混淆（终端提示符看venv名）；
- commit一次提交全部文件无说明。
