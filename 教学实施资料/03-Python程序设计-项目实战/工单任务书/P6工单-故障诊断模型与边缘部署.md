# 工单 P6《故障诊断模型与边缘部署》（第8周·4课时·难度⭐⭐⭐⭐·课程收官）

## 任务情境（v2.0：训练与推理分离）
将P2.2特征转化为诊断能力（F1≥0.80）并服务化部署；缺陷检测模型由教师端预训练产出（离线模型包），你聚焦评估调参与部署。本课含P7综合项目（第9周扩展，可选）说明。

## 课前导学单
1. 微课《sklearn五步流+模型上线》（6分钟）；
2. 预习自测：过拟合的信号是什么？怎么防？
3. 确认 `data/features.npy`（P2.2产物）与预训练模型包 `data/models/` 存在。

## 任务要求（P6.1分类诊断）
1. 五步流：划分→训练(LR/RF二选一)→交叉验证→调参(GridSearch)→joblib保存；
2. 混淆矩阵+报告：精确率/召回率/F1（目标F1≥0.80）；
3. 接入P5数据库：新入库记录→抽特征→预测→结果写回诊断字段。

## 任务要求（P6.2部署）
1. 预训练缺陷模型（教师包）本地推理测试（≥10样本）；
2. 封装推理服务：http.server实现 `POST /predict`（JSON入JSON出）；
3. 性能测试：单次推理延迟、100次平均延迟；
4. 版本管理：模型文件命名 `model_v1.joblib` + 版本说明行。
