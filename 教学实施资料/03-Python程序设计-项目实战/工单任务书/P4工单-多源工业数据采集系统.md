# 工单 P4.1《多源工业数据采集与消息中间件系统》（第6周·4课时·难度⭐⭐⭐⭐）

## 任务情境（v2.0：骨架先行）
3台PLC（Modbus）+云端指令（MQTT）并发接入，去重/换算/告警/缓冲入库。**starter提供三线程架构骨架**，你聚焦协议集成与可靠性。

## 课前导学单
1. 微课《线程=窗口, Queue=传送带》（6分钟）；
2. 预习自测：为什么"共享list.append"有隐患而Queue安全？
3. 启动 `工具/plc_simulator.py` 并 `--check` 确认三台连通。

## 架构（骨架已给）
```
ModbusCollector(Thread) ──┐
MQTTSubscriber(Thread) ───┼→ Queue(maxsize=10000) → DataProcessor(Thread) → SQLite缓冲入库
                          │
                  告警: 振动>4.5mm/s → 日志+推送
```

## 任务要求
1. 三线程贯通：采集(0.5s×3台) / 订阅(device/+/status) / 处理(去重+÷10换算+单位换算+超限告警)；
2. 断线重连：连接失败退避重试（1s→2s→4s），2号PLC会随机掉线——正好实测；
3. 批量入库：每50条或每5秒写一次SQLite（复用P5前置：sqlite3即可）；
4. 运行统计：采集率=成功次数/应采次数（目标≥95%）。

## 避坑
- 线程内直接print混淆输出 → 用logging（带线程名）；
- Queue满时put阻塞 → put(timeout=1)+丢弃计数；
- 忘记daemon=True导致Ctrl+C退不出。
