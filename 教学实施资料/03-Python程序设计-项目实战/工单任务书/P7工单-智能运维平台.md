## 五、常见错误速查（学生版高频翻车点）

| 现象 | 原因 | 解决 |
|---|---|---|
| granian起不来 | 模块路径不对 | cd到 p77_smart_ops 再启动 |
| duckdb报STRUCT转换错 | 把整个dict传给了标量参数 | 绑定 `a["device"]` 再传 |
| kuzu重复主键 | CREATE边时又建了同名节点 | 边必须MATCH双端再CREATE |
| chroma首次卡住 | 默认嵌入要联网下载模型 | 用自带HashEmbedding（离线） |
| Litestar 422/400 | 处理器参数名/注解不符 | Request参数命名request；body参数注解dict |
