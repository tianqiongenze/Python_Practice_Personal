# 工单 0.4《工业设备继承体系》（第5周·4课时·难度⭐⭐⭐）

## 任务情境
设备类型多样（PLC/变频器/传感器）：共性（编号、启停）+个性（PLC有扫描周期、变频器有频率设定）。构建"基类+子类"继承体系，支持统一接口调用（多态）。

## 课前模仿预习
1. 微课《设备家族谱系：继承》跟打示例；
2. 预习自测：子类如何调用父类的`__init__`？
3. 画继承体系类图（Device→PLC/变频器/传感器，标注各自新增属性方法）。

## 任务要求
1. Device基类（沿用W04成果）+≥2个子类，实现继承与方法覆盖；
2. 子类新增个性化方法（PLC.scan_cycle()、变频器.set_freq(f)）；
3. 多态演示：循环调用所有设备 `start()`，观察不同子类行为差异；
4. docstring：每个类与方法写一行文档字符串。

## 验收标准
| 等级 | 标准 |
|------|------|
| 及格(D) | 1基类+2子类+继承覆盖；规范率≥75% |
| 良好(C) | 多态调用演示清晰；docstring齐全 |
| 优秀(B) | ≥3子类；规范率≥90%；覆盖方法内用super()协作 |
| 优(A) | 达B且体现"is-a"设计判断（说明为什么不用继承实现某设备） |

## 提交物
代码 + 类图照片 + 多态运行输出

## 避坑
- 覆盖 `__init__` 忘记 `super().__init__(...)` → 父类属性丢失；
- 为继承而继承（"车间"不是设备，不要继承Device）；
- 多态失败：子类方法名拼写与父类不一致（Start≠start）。
