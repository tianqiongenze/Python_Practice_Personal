# 工单 1.2《工业数据文件处理系统》（第8周·4课时·难度⭐⭐）

## 任务情境
历史运行数据（CSV/JSON）需集中清洗入库：剔缺失、修类型、查越界，输出可信标准数据集。

## 课前导学单
1. 微课《with open与JSON》；
2. 预习自测：with语句的好处是什么？
3. starter里生成了一份"脏数据CSV"，预习时先跑一遍数一数问题行。

## 任务要求
1. 用 with open 读写CSV与JSON（starter生成样例数据）；
2. 数据验证三维度：缺失（空值）、类型（数值字段含"err"）、范围（温度>120判越界）；
3. 问题行策略：跳过并记录（list收集+写bad.csv）；
4. 输出清洗后CSV + 清洗报告（各维度问题计数）；
5. 决策：编码统一UTF-8（GBK样例文件演示坑）。

## 验收标准
| 等级 | 标准 |
|------|------|
| 及格(D) | 读写≥2种格式+基本验证；规范率≥75% |
| 良好(C) | 三维验证齐全；bad.csv可追溯 |
| 优秀(B) | 清洗报告清晰；输出规范列名；规范率≥90% |
| 优(A) | 达B且支持命令行参数选择输入文件 |

## 提交物
代码 + 清洗后CSV + 清洗报告文本

## 避坑
- open不close（用with）；
- float("err")崩溃 → 先判断再转，异常捕获；
- 相对路径在IDE与命令行不一致 → os.path按脚本目录拼接。
