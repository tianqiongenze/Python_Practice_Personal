# 工单 0.5《健壮的工业数据采集程序》（第6周·4课时·难度⭐⭐·含中期诊断）

## 任务情境
采集程序在现场常因文件缺失、数据格式错误崩溃停摆。运维要求"出错不停机、留痕可追溯"。

## 课前模仿预习
1. 微课《try/except与日志》跟打示例；
2. 预习自测：finally块无论是否异常都执行吗？
3. 预习：logging比print好在哪（写2条）。

## 任务要求
1. 模拟采集：读取设备数据文件（starter自动生成，含2条脏数据）；
2. 捕获≥2种异常（FileNotFoundError / ValueError），禁止裸except；
3. try/except/finally完整结构至少1处；
4. logging日志：INFO记录正常、WARNING记录脏数据跳过、ERROR记录异常，输出到文件+控制台；
5. 程序结束时输出"采集统计"（成功/跳过/失败条数）。

## 验收标准
| 等级 | 标准 |
|------|------|
| 及格(D) | 处理≥2种异常+基本日志；规范率≥75% |
| 良好(C) | 三级日志分明；统计输出正确 |
| 优秀(B) | ≥3种异常+完整finally；日志可定位到行；规范率≥90% |
| 优(A) | 达B且脏数据自动写入bad_records.csv备查 |

## 避坑
- `except:` 裸捕获吞掉KeyboardInterrupt → 禁止；
- 日志中文乱码 → logging.FileHandler(..., encoding="utf-8")；
- 在except里pass什么都不做 → 至少记录ERROR并继续。
