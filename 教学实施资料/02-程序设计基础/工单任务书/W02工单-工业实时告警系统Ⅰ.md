# 工单 0.2a《工业实时告警系统Ⅰ：条件判断》（第2周·4课时·难度⭐⭐）

## 任务情境
中控室要求对设备温度/压力自动分级告警：超预警线提示、超危险线报警停机。本次完成判断逻辑。

## 课前模仿预习
1. 微课《if/elif/else》（4分钟）跟打示例；
2. 预习自测：`temp >= 80` 与 `temp > 80` 在 temp=80 时结果？
3. 画一张两级告警流程图（手绘拍照带上）。

## 任务要求
1. 实现≥2个if条件判断（温度阈值80/95℃，压力阈值0.8MPa）；
2. 设计≥1个告警函数 `def alarm(level, msg)`；
3. 边界测试：79.9 / 80 / 94.9 / 95 / 100 五组值全覆盖；
4. 逻辑组合：温度与压力**同时**超限 → 升级为"紧急"。

## 验收标准
| 等级 | 标准 |
|------|------|
| 及格(D) | ≥2个if判断+1个告警函数；规范率≥70% |
| 良好(C) | 边界五组测试全对 |
| 优秀(B) | 多条件嵌套（提示/警告/停机三级）；规范率≥85% |
| 优(A) | 达B且循环测试3台设备（为W3铺垫） |

## 提交物
代码 + 边界测试输出记录（5组）

## 避坑
- `=` 与 `==` 混用；
- elif 顺序错误（先判>80再判>95 → 永远到不了95分支）；
- and/or 优先级：`a>80 and b>0.8 or c` 加括号最稳。
