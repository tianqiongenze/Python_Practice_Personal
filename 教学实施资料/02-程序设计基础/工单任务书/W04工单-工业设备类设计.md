# 工单 0.3《工业设备类设计》（第4周·4课时·难度⭐⭐）

## 任务情境
设备台账扩至数十台，散装变量难以维护。用"类"给设备建模：属性=铭牌参数，方法=操作行为。（本周只做基本类，不讲继承。）

## 课前模仿预习
1. 微课《图纸与产品：类与对象》跟打Device类示例；
2. 预习自测：`__init__` 什么时候执行？self指谁？
3. 口头描述：一台变频器有哪些属性和方法（写在预习单）。

## 任务要求
1. 设计 Device 类：≥2属性（id、name、status、temp任选）+≥2方法（start/stop/get_status）；
2. 使用 `__init__` 构造方法；
3. 创建≥2个设备对象并演示属性访问、方法调用；
4. 打印对象时输出可读信息（`__str__`，选做加分）。

## 验收标准
| 等级 | 标准 |
|------|------|
| 及格(D) | 1类+2属性+2方法+2实例；规范率≥75% |
| 良好(C) | 方法含状态校验（已启动再start给出提示） |
| 优秀(B) | ≥3属性+≥3方法+3实例；规范率≥90% |
| 优(A) | 达B且方法间有协作（stop后自动记录日志字符串） |

## 提交物
代码 + 对象调用输出截图

## 避坑
- 方法漏写 self 参数 → 调用时报"多传了一个参数"；
- 属性直接在类体定义被所有实例共享 → 实例属性写在 `__init__` 里；
- `d.start` 少括号 → 拿到方法对象而不是调用。
