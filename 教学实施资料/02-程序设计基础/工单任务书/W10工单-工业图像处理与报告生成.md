# 工单 1.4《工业图像处理与报告生成》（第10周·4课时·难度⭐⭐⭐）

## 任务情境
质检照片需标注缺陷区域并汇总成图文PDF质量日报报送管理层——"程序输出要面向使用者"。

## 课前导学单
1. 微课《Pillow画框与reportlab排版》；
2. 预习自测：PDF坐标系原点在页面哪个角？
3. 浏览starter的报告模板，想好你的日报标题。

## 任务要求
1. 用Pillow生成/读取设备图片，缩放统一尺寸（400×300）；
2. ImageDraw在缺陷区域画红框+文字标注（坐标starter给定）；
3. reportlab生成PDF：标题+段落（日报结论）+标注图+统计表（SimpleTable）；
4. 中文字体注册（fonts/SimHei.ttf → pdfmetrics.registerFont）。

## 验收标准
| 等级 | 标准 |
|------|------|
| 及格(D) | 图像标注完成+PDF可生成；规范率≥80% |
| 良好(C) | PDF含图+表+结论三要素 |
| 优秀(B) | 排版专业（页边距/对齐/字号层级）；规范率≥90% |
| 优(A) | 达B且多页报告（首页概览+次页明细）或自绘封面 |

## 提交物
代码 + 标注图 + PDF报告

## 避坑
- PDF中文不显示 → 必须注册中文字体后setFont；
- draw.text坐标在框下方会被裁 → y-12再画；
- Image.open后直接Draw原图会污染 → 用copy()。
