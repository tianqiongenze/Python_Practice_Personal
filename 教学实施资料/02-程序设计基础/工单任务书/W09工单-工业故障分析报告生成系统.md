# 工单 1.3《工业故障分析报告生成系统》（第9周·4课时·难度⭐⭐⭐）

## 任务情境
运维部要"一页纸"故障规律报告：读故障文本→jieba分词→关键词提取→词云+柱状图。

## 课前导学单
1. 微课《分词与词云》；
2. 预习自测：pip离线装jieba的命令？
3. 每人收集2条设备故障描述（课前提交，汇入班级语料）。

## 任务要求
1. 读取故障文本（starter内置50条，可合并班级语料）；
2. jieba精确模式分词+停用词过滤；
3. jieba.analyse.extract_tags 提取Top20关键词；
4. wordcloud生成词云（中文字体随包 fonts/SimHei.ttf；禁止默认字体→方块）；
5. matplotlib柱状图Top10词频；
6. 撰写≤150字故障规律洞察（哪个系统故障集中？关键词说明什么？）。

## 验收标准
| 等级 | 标准 |
|------|------|
| 及格(D) | 分词正确+词云生成；规范率≥80% |
| 良好(C) | 停用词处理得当；词频图正确 |
| 优秀(B) | 词云美观（蒙版/配色）；洞察有数据支撑；规范率≥90% |
| 优(A) | 达B且按系统分组对比词云（传动vs电气） |

## 提交物
代码 + 词云PNG + 柱状图PNG + 洞察文字

## 避坑
- 词云中文变方块 → WordCloud(font_path="fonts/SimHei.ttf")；
- 未过滤停用词 → "的/了"霸榜；
- generate_from_frequencies 与 generate 混用（一个收字典一个收字符串）。
