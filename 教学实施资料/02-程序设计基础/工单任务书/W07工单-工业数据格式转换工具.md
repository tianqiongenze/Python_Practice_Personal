# 工单 1.1《工业数据格式转换工具》（第7周·4课时·难度⭐⭐·六步法启动周）

## 任务情境
车间设备数据以多种格式混杂（文本报文、CSV、JSON），上位系统无法直接使用。开发标准化转换工具。

## 课前导学单（六步之"资讯·计划"，线上完成）
1. 微课《列表、字典与正则八块积木》；
2. 预习自测：`\d` `+` `[]` 分别匹配什么？
3. 提交初步计划：你准备先解析哪种格式？步骤3条。

## 任务要求
1. 解析报文串 `"DEV-01:temp=56.3C;press=0.45MPa;status=RUN"`（正则提取键值）；
2. 解析CSV行与JSON串各≥1种（starter提供样例）；
3. 统一转换为标准字典结构 `{"device_id":..., "metrics":{...}}`；
4. 决策（课堂10min）：容器选型矩阵——何时用列表/字典/集合？写入工单。

## 验收标准
| 等级 | 标准 |
|------|------|
| 及格(D) | 处理≥2种格式+使用正则；规范率≥75% |
| 良好(C) | 三种格式全通；字典结构统一 |
| 优秀(B) | ≥3种格式+容错（缺字段/乱序报文）；规范率≥90% |
| 优(A) | 达B且批量转换文件并输出转换统计 |

## 提交物
代码 + 决策矩阵照片 + 转换输出样例

## 避坑
- 正则贪婪匹配 `(.*)` 吞整行 → 用 `([\d.]+)` 限定；
- 字典嵌套访问 KeyError → 用 .get()；
- 忘记strip()导致键名带空格。
