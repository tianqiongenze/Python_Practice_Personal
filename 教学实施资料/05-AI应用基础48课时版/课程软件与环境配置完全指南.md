## 二、基础环境三步装

1. **Anaconda+conda环境**：安装Anaconda→创建课程环境`conda create -n ai48 python=3.12 -y`→激活`conda activate ai48`（详见`../软件操作指南/01-Anaconda安装与使用指南.md`）
2. **PyCharm CE**：装Python扩展+Jupyter扩展；选conda环境`ai48`作为解释器（详见`05-PyCharm使用指南.md`第三章）
3. **依赖**（**必须先`conda activate ai48`再装**）：
   ```bash
   conda activate ai48
   pip install numpy pandas scikit-learn matplotlib xgboost jieba requests
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
   pip install onnxruntime opencv-python notebook
   ```
   离线机房：教师机`pip download`上述清单（含cpu版torch/torchvision）→学生机`conda activate ai48 && pip install --no-index --find-links offline_wheels/`安装（同01包流程）。

## 五、环境故障排查（本课实测案例）

| 现象 | 原因 | 解决 |
|------|------|------|
| xgboost fit报"JSON: Unknown parameter" | 新版需显式eval_metric | `XGBClassifier(eval_metric="logloss")` |
| torchvision下载权重超时 | 机房无外网 | 用第三节离线权重法 |
| 装torch后sklearn/matplotlib异常 | 旧版torch与numpy 2.x不兼容 | `pip install --upgrade torch`（torch 2.14+已兼容numpy 2.x，升级torch而非回退numpy） |
| W15想装gym | 不需要 | 本课`mini_sched_env`自包含，接口风格相近（reset/step/done） |
| MLP loss=nan | 未标准化/学习率大 | StandardScaler+默认lr |
| W6 sliding_window对齐报错 | X与y长度差 | 统一`[:-horizon]`截断（见starter注释） |
